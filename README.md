The idea behind the project is to be able to manage the planning of my weekly schedule from the terminal

For the first draft, it needs to be able to:
  - Display the current week's schedule - STATUS: almsot completed
  - Have the ability to add and store new timeblocks
  - Have the ability to remove past timeblocks
  - Have the ability to move past timeblocks
